Projeto meta-heurístico implemento um algoritmo genético para ajuste de função linear.

O trabalho foi modularizado em pastas e é executado através de um makefile responsável por recompilar o programa a cada execução, garantindo que nenhum cashe afete a execução.

Os pontos utilizados no main.c são gerados randomicamente através de uma seed fixa em gerar.c.

No main.c, abri o input.dat gerado pelo gerar.c e li os parâmetros n, m e G, peças fundamentais para a análise de fitting futura.
